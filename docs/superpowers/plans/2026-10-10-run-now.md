# Run now button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Run now" button on the dashboard Runs page that starts a real job search in the background and redirects back to the Runs page.

**Architecture:** `index.js`'s `fetch` handler passes `run` into `handleRequest` as a dependency (`deps.run`), so `http.js` never imports `index.js`. A new `POST /runs/now` route checks the origin header, skips the start when a `running` row is under 10 minutes old, otherwise hands `deps.run()` to `ctx.waitUntil`, and always answers `303` to `/runs`. The Runs page renders one extra form. No schema change.

**Tech Stack:** Cloudflare Worker, plain JS ESM, no bundler, `node:test` with `node:sqlite` fakes. Run tests with `npm test` (Node 22.13+).

**Spec:** `docs/superpowers/specs/2026-10-10-run-now-design.md`

## Global Constraints

- Plain JS ESM. No TypeScript, no build step, no new dependencies.
- `src/store.js` is the only module with SQL. This plan adds no SQL.
- `src/http.js` must not import `src/index.js` (circular import).
- No client-side JavaScript on the dashboard. No CSP change.
- Never log an Adzuna URL. `run()` already handles this; the new code logs only `err.message`.
- No new D1 column, no migration.
- `.claude/settings.json` runs `npm test` after every Edit or Write. A failing suite blocks the edit, so write the failing test and the implementation in the order given and expect the hook to report the failure in between.
- Dates in docs as YYYY-MM-DD. No em dashes in any text.

## Review Focus

1. `latestRun` returns a `running` row whose `started_at` is unparseable (bad text in D1). Expected: treat as not in progress and start a run, not throw. Pinned in Task 2.
2. `POST /runs/now` arrives with `ctx.waitUntil` missing (a test or a future harness). Expected: the route still responds 303 and the run still starts. Pinned in Task 2.
3. A `running` row with `started_at` in the future (clock skew). Expected: treated as in progress (age is negative, under 10 minutes), no second run. Pinned in Task 2.
4. `deps.run` is not supplied (someone calls `handleRequest` the old three-argument way). Expected: the route responds 303 and starts nothing, instead of throwing a TypeError into the 500 path. Pinned in Task 2.
5. The Runs page button must render in the empty state too, since the first ever press happens with no runs. Pinned in Task 3.

// Helpers for the Run now route. deps.run resolves by default; pass a rejecting
// fn to test the failure path. waited collects what the route hands to waitUntil.
function runNow({ origin = "https://jobs.example", db = fakeDb(), run, waitUntil } = {}) {
  const waited = [];
  const calls = [];
  const deps = {
    run: run ?? (async () => { calls.push(1); }),
  };
  const ctxNow = {
    access: { aud: "test" },
    waitUntil: waitUntil === null ? undefined : (p) => waited.push(p),
  };
  const headers = { "content-type": "application/x-www-form-urlencoded" };
  if (origin !== null) headers.origin = origin;
  const req = new Request("https://jobs.example/runs/now", { method: "POST", headers, body: new URLSearchParams() });
  return handleRequest(req, { DB: db }, ctxNow, deps).then((res) => ({ res, waited, calls }));
}

async function runningRowStarted(db, isoStartedAt) {
  await db.prepare("INSERT INTO runs (started_at, outcome) VALUES (?, 'running')").bind(isoStartedAt).run();
}

const minutesAgo = (m) => new Date(Date.now() - m * 60_000).toISOString();

test("POST /runs/now starts a run in the background and redirects to /runs", async () => {

test("POST /runs/now rejects a missing or foreign Origin with 403 and starts nothing", async () => {

- [ ] **Step 5: Add `startRunNow`**

In `src/http.js`, after the `updateStatus` function and before `handleRequest`:

```js
function runInProgress(latest) {
  if (latest?.outcome !== "running") return false;
  const startedAt = new Date(latest.started_at).getTime();
  if (Number.isNaN(startedAt)) return false;
  return Date.now() - startedAt < RUN_IN_PROGRESS_MS;
}

// Starts a real run (same as the cron) in the background and sends the browser
// back to the Runs page, where the new row shows as running.
async function startRunNow(request, env, ctx, deps, url) {
  // CSRF guard: the form must come from this host.
  if (parseUrl(request.headers.get("origin"))?.host !== url.host) return text("Forbidden", 403);
  const redirect = new Response(null, { status: 303, headers: { location: `${url.origin}/runs` } });
  if (typeof deps?.run !== "function") return redirect;
  if (runInProgress(await latestRun(env.DB))) return redirect;
  const pending = deps.run().catch((err) => {
    console.error(`Run now failed: ${err?.message ?? err}`);
  });
  if (typeof ctx?.waitUntil === "function") ctx.waitUntil(pending);
  return redirect;
}
```
